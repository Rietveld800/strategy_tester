What counts as the same

The same levels means the same market, the same side and the same first reversal price, inside one continuous level run: the consecutive array files that carry that level as an eligible ladder member. A level that is elected and reappears later starts a fresh episode, because the market has been somewhere else in between. A test is a maximal run of minutes whose bar range contains the level, so a level price sits on for six minutes was tested once, and price has to leave and come back to test it again. Tests are counted whether or not they produced a trade, which is what makes them the wider measure.
